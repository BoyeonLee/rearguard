## A. 카메라·기기 설정
──────────────────────────────

A1. 스마트폰 기종 등급
[ ] 플래그십(최근 3년)  [ ] 보급형  [ ] 구형(4년 이상)  [ ] 모름/미정
→ 왜: 기기 연산 성능에 따라 실시간으로 돌릴 수 있는 전처리의 양과 입력 해상도 상한이 정해진다.

A2. 촬영 해상도
[ ] 720p  [ ] 1080p  [ ] 4K  [ ] 모름/미정
→ 왜: 원본 해상도에 따라 모델 입력 크기로 줄이는 리사이즈 비율과 먼 차량의 픽셀 크기가 결정된다.

A3. 프레임 레이트(FPS)
[ ] 24fps  [ ] 30fps  [ ] 60fps  [ ] 모름/미정
→ 왜: 프레임 간격이 속도·TTC 계산의 시간 단위가 되고, 프레임 건너뛰기(샘플링) 설정의 기준이 된다.

A4. 사용 렌즈
[ ] 일반(메인)  [ ] 초광각  [ ] 망원  [ ] 모름/미정
→ 왜: 초광각은 렌즈 왜곡이 커서 거리 계산 전에 왜곡 보정(undistortion)이 필수가 된다.

A5. 손떨림 보정(OIS/EIS)
[ ] 켜짐  [ ] 꺼짐  [ ] 기기에서 끌 수 없음  [ ] 모름/미정
→ 왜: 전자식 보정(EIS)은 화면을 몰래 잘라내고 움직여서 카메라 캘리브레이션 값을 틀어지게 만들 수 있다.

A6. HDR 모드
[ ] 켜짐  [ ] 꺼짐  [ ] 자동  [ ] 모름/미정
→ 왜: HDR 처리 여부에 따라 역광·명암 대비 보정을 별도로 해야 하는지가 달라진다.

A7. 노출·초점 설정
[ ] 자동  [ ] 잠금(고정)  [ ] 모름/미정
→ 왜: 자동 노출은 차량 진입 시 밝기가 출렁여서 밝기 정규화나 노출 고정 설정이 필요한지를 결정한다.

## B. 거치 조건
──────────────────────────────

B1. 장착 높이(지면~카메라)
[ ] 60cm 미만  [ ] 60~80cm  [ ] 80~100cm  [ ] 100cm 이상  [ ] 모름/미정
→ 왜: 지면 평면 호모그래피의 핵심 입력값이며, 화면에서 도로가 차지하는 영역(ROI) 범위를 결정한다.

B2. 카메라 기울기
[ ] 수평  [ ] 약간 아래(10° 이내)  [ ] 많이 아래(10° 초과)  [ ] 모름/미정
→ 왜: 기울기에 따라 하늘·도로 비율이 달라져 관심 영역 크롭 위치와 거리 계산 보정값이 바뀐다.

B3. 화면 내 가림 요소 (복수)
[ ] 없음  [ ] 뒷바퀴/펜더  [ ] 라이더 다리  [ ] 안장가방  [ ] 마운트·케이블  [ ] 모름/미정
→ 왜: 항상 같은 위치에 보이는 가림 영역은 마스킹(검게 가리기)으로 제외해야 오검출이 줄어든다.

B4. 마운트 고정 상태
[ ] 매우 단단함  [ ] 약간 흔들림  [ ] 심하게 흔들림  [ ] 모름/미정
→ 왜: 흔들림 정도에 따라 영상 안정화 필터의 필요 여부와 강도가 결정된다.

B5. 주행 중 마운트 각도 변화
[ ] 없음  [ ] 가끔 틀어짐  [ ] 자주 틀어짐  [ ] 모름/미정
→ 왜: 각도가 변하면 IMU 기반 실시간 각도 보정을 전처리 단계에 넣어야 한다.

## C. 주행 조건
──────────────────────────────

C1. 자전거 주행 속도
[ ] 15km/h 미만  [ ] 15~25km/h  [ ] 25km/h 이상  [ ] 모름/미정
→ 왜: 속도가 빠를수록 모션 블러가 커져 셔터 속도 설정이나 블러 대응 증강이 필요해진다.

C2. 노면 상태 (복수)
[ ] 매끈한 아스팔트  [ ] 보도블록  [ ] 요철·과속방지턱 잦음  [ ] 비포장  [ ] 모름/미정
→ 왜: 노면 진동의 크기와 주기가 영상 안정화 및 추적 필터(칼만 필터) 노이즈 설정의 기준이 된다.

C3. 주요 주행 도로 (복수)
[ ] 시내 일반도로  [ ] 교외 도로  [ ] 자전거 전용도로  [ ] 골목길  [ ] 모름/미정
→ 왜: 도로 유형에 따라 등장하는 차량 종류와 배경 복잡도가 달라져 학습 데이터 구성 비율이 바뀐다.

C4. 도로 형태 (복수)
[ ] 평지 직선  [ ] 경사로  [ ] 굴곡로  [ ] 교차로 잦음  [ ] 모름/미정
→ 왜: 경사·굴곡은 "도로가 평평하다"는 거리 계산 가정을 깨뜨려 해당 구간 필터링이나 보정이 필요하다.

## D. 환경 조건
──────────────────────────────

D1. 촬영 시간대 (복수)
[ ] 주간  [ ] 일출·일몰(박명)  [ ] 야간  [ ] 모름/미정
→ 왜: 시간대별 밝기 분포에 따라 밝기·대비 정규화 방식과 저조도 보정 필요 여부가 정해진다.

D2. 날씨 (복수)
[ ] 맑음  [ ] 흐림  [ ] 비  [ ] 안개  [ ] 모름/미정
→ 왜: 악천후 데이터 비율은 노이즈 제거 필터 사용 여부와 날씨 증강(비·안개 합성) 범위를 결정한다.

D3. 조명 특이 상황 (복수)
[ ] 역광(해를 등지고 촬영)  [ ] 강한 그림자  [ ] 터널·고가 아래 명암 급변  [ ] 차량 전조등 눈부심  [ ] 해당 없음
→ 왜: 급격한 명암 변화는 히스토그램 평활화(CLAHE) 같은 국소 대비 보정의 필요성을 판단하는 근거다.

D4. 렌즈 오염 가능성 (복수)
[ ] 먼지  [ ] 빗방울  [ ] 흙탕물 튐  [ ] 거의 없음  [ ] 모름/미정
→ 왜: 후방 카메라는 뒷바퀴 튐에 노출되므로 오염 영상을 걸러내는 품질 검사 단계가 필요한지 판단한다.

## E. 탐지 대상(차량)·장면 특성
──────────────────────────────

E1. 자주 등장하는 차량 (복수, 많은 순으로 번호 기입 가능)

→ 왜: 차종별 데이터 양의 차이는 클래스 불균형 처리(오버샘플링, 가중치)의 기준이 된다.

E2. 차량이 처음 보이는 거리
[ ] 10m 이내  [ ] 10~30m  [ ] 30~50m  [ ] 50m 이상  [ ] 모름/미정
→ 왜: 먼 차량은 화면에서 매우 작게 보여 입력 해상도와 소형 객체 대응 전처리 수준을 결정한다.

E3. 한 화면에 동시에 보이는 차량 수
[ ] 0~1대  [ ] 2~3대  [ ] 4대 이상  [ ] 모름/미정
→ 왜: 차량이 많을수록 겹침(가림)이 늘어 추적 매칭 설정과 라벨링 규칙이 복잡해진다.

E4. 차량끼리 겹침 빈도
[ ] 거의 없음  [ ] 가끔  [ ] 자주  [ ] 모름/미정
→ 왜: 겹침이 잦으면 부분만 보이는 차량을 라벨링할지에 대한 기준과 가림 증강이 필요하다.

E5. 배경 복잡도 (복수)
[ ] 단순(도로·하늘 위주)  [ ] 주차 차량 많음  [ ] 간판·건물 많음  [ ] 보행자 많음
→ 왜: 주차 차량처럼 움직이지 않는 차량을 걸러내는 필터(정지 객체 제외)가 필요한지 판단한다.

E6. 뒤차와의 상대 속도
[ ] 느림(20km/h 미만)  [ ] 보통(20~40km/h)  [ ] 빠름(40km/h 이상)  [ ] 모름/미정
→ 왜: 상대 속도가 빠르면 프레임 간 이동량이 커져 추적 필터의 예측 범위와 처리 FPS 하한이 높아진다.

→ 왜: 정답값이 있어야 거리 추정 단계의 보정 파라미터를 맞추고 전처리 효과를 수치로 검증할 수 있다.
