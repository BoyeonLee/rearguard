| 핸들 유닛 | **S8050** NPN 트랜지스터 | Vce 최대 25V | 부저 전류 통과 | GPIO 베이스 구동 |
| 전원 | Li-Po 1S **3.7V** (후방 1000mAh / 핸들 500mAh), 보호회로 내장 | 3.0~4.2V | 방전 1C 이상 | 아날로그 (ADC로 전압 감시) |
| 테스트 촬영 | iPhone + 삼각대 (60·70·80cm) | 자체 전원 | 해당 없음 | 파일 전송 (MP4/JPG) |

**한 줄로:** "두 경고 유닛은 같은 XIAO ESP32-C3 + 1셀 Li-Po로 통일하고, GPIO가 감당할 수 없는 부하(파워 LED 300mA, 부저 40mA)는 **반드시 트랜지스터로 분리**하며, 전원은 **피크 전류 기준**으로 설계한다."

- 설계 원칙 1 (전압은 맞추고 전류는 확보한다): ESP32-C3 GPIO는 3.3V 출력이며 핀당 권장 20mA 이하다. 파워 LED는 MOSFET, 부저는 NPN으로 분리한다.
- 설계 원칙 2 (피크 기준): 후방 유닛 피크 약 430mA, 핸들 유닛 피크 약 210mA. 두 배터리 모두 1C 방전으로 여유 있게 견딘다(§5).
- 설계 원칙 3 (공통 GND): 배터리, MCU, LED, 부저의 GND를 한 점으로 묶는다.

> 참고: 전류 값 중 "데이터시트"로 표시하지 않은 것은 **설계 가정값**이다. 조립 후 멀티미터로 실측해 §5 전력 예산표를 갱신한다(§8 검증 항목 H2).

## 2. 공통 부품

### 2.1 MCU: Seeed Studio XIAO ESP32-C3 (×2)

| 항목 | 사양 |
|---|---|
| 칩 | ESP32-C3 (RISC-V 단일 코어 160MHz, SRAM 400KB, 플래시 4MB) |
| 무선 | Wi-Fi 2.4GHz + **Bluetooth 5.0 LE** (PoC에서는 Wi-Fi 끔) |
| 전원 입력 | USB-C 5V, 또는 뒷면 BAT 패드에 Li-Po 3.7V |
| 로직 전압 | **3.3V** (5V 입력 불가 핀. 모든 GPIO는 3.3V 기준) |
| 소비 전류 (설계 가정) | BLE 연결 유지 평균 약 60mA, 송신 순간 피크 약 130mA |
| GPIO 출력 전류 | 핀당 권장 **20mA 이하** (최대 구동 세기 설정 시 약 40mA) |
| 충전 | Li-Po 충전 회로 내장: USB-C를 꽂으면 BAT 패드의 배터리를 충전 |
| 크기 | 21 × 17.5mm |
| 통신 | BLE GATT(노트북), USB Serial/JTAG(펌웨어 업로드·시리얼 로그) |

**선정 이유**
- BLE 내장, Li-Po 충전 회로 내장이라 별도 충전 모듈이 필요 없다(조건 ②④).
- 엄지손톱 크기라 후방·핸들 유닛 모두 작은 케이스에 들어간다.
- Arduino-ESP32와 ESP-IDF 모두 지원하며, LEDC(PWM)·RMT(WS2812B 신호) 주변장치가 있다.

**차선책:** ESP32-C3 SuperMini(더 저렴하지만 충전 회로 없음 → TP4056 충전 모듈 추가 필요), ESP32-S3 계열(성능은 높지만 이 용도에 과함).

### 2.2 배터리: Li-Po 1셀 3.7V (보호회로 내장)

| 항목 | 후방 유닛 | 핸들 유닛 |
|---|---|---|
| 용량 | 1000mAh | 500mAh |
| 전압 범위 | 3.0V(방전 종지) ~ 3.7V(공칭) ~ 4.2V(만충) | 동일 |
| 방전 능력 | 1C 이상 (1.0A) | 1C 이상 (0.5A) |
| 피크 부하 | 약 430mA (0.43C) | 약 210mA (0.42C) |
| 커넥터 | JST-PH 2.0mm 2핀 | 동일 |
| 필수 조건 | **보호회로(PCM) 내장** 제품 | 동일 |

> 주의: JST-PH 커넥터의 **+/− 극성이 판매처마다 반대인 경우가 있다.** XIAO BAT 패드에 납땜하기 전 멀티미터로 극성을 반드시 확인한다. 극성을 반대로 연결하면 보드가 손상된다.

### 2.3 배터리 전압 감시 회로 (각 유닛)

XIAO ESP32-C3에는 배터리 전압 측정 회로가 없으므로 저항 분압을 직접 단다.

| 부품 | 값 | 이유 |
|---|---|---|
| 분압 저항 | 220kΩ × 2 (1:2 분압) | 4.2V → 2.1V로 낮춰 ADC 입력 범위(약 0~2.5V, 11dB 감쇠) 안에 넣음. 상시 소모 약 10µA |
| 필터 커패시터 | 100nF (ADC 핀–GND) | 큰 저항으로 생기는 ADC 측정 흔들림 완화 |
| 연결 핀 | GPIO3 (D1, ADC1) | ADC2(GPIO5)는 무선 사용 중 읽기가 불안정하므로 피함 |

- 펌웨어에서 3.5V 이하면 저전압 경고(핸들 LED 파랑 점멸), 3.3V 이하면 출력 정지로 배터리를 보호한다.

### 2.4 전원 스위치 (각 유닛)

| 부품 | 사양 | 위치 |
|---|---|---|
| 슬라이드 스위치 (SPDT) | 정격 0.5A 이상, 3.7V | 배터리 + 선과 BAT 패드 사이 |

> 스위치를 끈 상태에서도 USB-C를 꽂으면 보드는 켜지지만 배터리는 충전되지 않는다. 충전할 때는 스위치를 켠다.

### 3.2 파워 LED 전류 계산

LED는 배터리(VBAT)에서 직접 전원을 받고, MOSFET이 GND 쪽을 끊었다 이었다 한다.

```
R = (VBAT_max − Vf − I × Rds) / I_max
  = (4.2V − 2.2V − 0.3A × 0.05Ω) / 0.3A ≈ 6.6Ω  →  6.8Ω 선택
```

| 배터리 전압 | LED 전류 (Vf 2.2V 가정) | 저항 소비 전력 |
|---|---|---|
| 4.2V (만충) | 약 290mA | 약 0.57W |
| 3.7V (공칭) | 약 220mA | 약 0.33W |
| 3.5V (저전압 경고) | 약 190mA | 약 0.25W |

- 저항은 1W 이상이 필요하고, 발열 여유를 위해 **2W**를 쓴다.
- LED 자체 소비도 최대 약 0.65W이므로 **알루미늄 스타 기판에 붙은 제품**을 쓰고 케이스 안에 통풍 구멍을 둔다.
- 배터리가 줄면 밝기가 함께 떨어지는 것이 저항 방식의 한계다. PoC에서는 허용하고, 밝기 일정성이 문제가 되면 정전류 LED 드라이버로 바꾼다(§7 R3).

> 주의: 흔히 파는 **IRF520 MOSFET 모듈은 쓰지 않는다.** 게이트 문턱 전압이 2~4V라 ESP32의 3.3V로는 완전히 켜지지 않아 MOSFET이 뜨거워지고 LED가 어둡다. 3.3V에서 확실히 켜지는 **로직 레벨 MOSFET**(AO3400A, 또는 TO-220 패키지의 IRLB8721)을 쓴다.

### 3.3 위험도별 출력 (초기값, PRD F3 기준)

| 단계 | PRD 후방 LED | PWM 듀티 | 점멸 | 평균 전류 |
|---|---|---|---|---|
| 0 안전 / 1 주의 | 기본 점등 | 30% | 상시 점등 | 약 90mA |
| 2 경고 | 고휘도 점멸 | 70% | 2Hz | 약 105mA |
| 3 위험 | 최대 밝기 점멸 | 100% | 3Hz | 약 150mA |

- PWM 주파수는 **5kHz**: 사람 눈과 휴대폰 카메라 모두에서 깜빡임(플리커)이 보이지 않는 대역.
- 점멸 주기는 3Hz 이하로 시작한다(눈부심·광과민 반응 방지, PRD F3 "점멸 주기 기준"). 실험으로 조정한다.
- **BLE 연결이 1초 이상 끊기면 0단계(기본 점등)로 돌아간다.** 통신이 끊겨도 후방등 역할은 유지한다.

### 3.4 배선도

```
 Li-Po(+) ── 스위치 ──┬── XIAO BAT+ 
                      ├── 100µF(+) ── GND
                      ├── 220kΩ ──┬── 220kΩ ── GND
                      │           └── GPIO3 (ADC) ── 100nF ── GND
                      └── 1W LED(애노드) ─ LED(캐소드) ── 6.8Ω 2W ── AO3400A 드레인
                                                                     AO3400A 소스 ── GND
 GPIO10 ── 100Ω ── AO3400A 게이트 ── 100kΩ ── GND
 Li-Po(−) ── XIAO BAT− ── GND (모든 GND 공통)
```

### 4.2 부품 선택 이유

**RGB LED → 일반 4핀 RGB LED가 아니라 WS2812B를 고른 이유**
- 일반 RGB LED의 초록·파랑은 Vf가 약 3.0~3.2V라, 3.3V GPIO로 직접 켜면 전압 여유가 0.1~0.3V뿐이라 어둡고 색이 불안정하다. 노랑·주황은 빨강+초록을 섞어야 하므로 초록이 어두우면 색이 틀어진다.
- WS2812B는 칩 안에 정전류 구동 회로가 있어 배터리 전압이 변해도 색이 일정하고, **신호선 1개**로 색과 밝기를 정한다.
- 전압 레벨 확인: WS2812B의 입력 High 기준은 0.7×VDD. VDD가 만충 4.2V일 때 2.94V이므로 ESP32의 3.3V 신호로 인식된다. (VDD를 USB 5V로 주면 기준이 3.5V가 되어 인식이 불안정하므로 **반드시 배터리 전압으로 공급**한다.)
- VDD 최소 3.5V는 §2.3의 저전압 경고 기준과 같다. 그 아래로 내려가기 전에 사용자에게 충전을 알린다.

**부저 → 수동형 + 트랜지스터를 고른 이유**
- PRD는 "짧은 비프"와 "연속음"을 구분한다. 수동형은 PWM 주파수와 길이를 펌웨어로 바꿀 수 있어 단계별 소리를 다르게 만들 수 있다(능동형은 고정음).
- 전자식(코일) 부저는 압전 부저보다 소리가 커서 도로 소음 속에서도 들린다. 대신 30~40mA를 먹으므로 GPIO 권장 전류(20mA)를 넘어 **NPN으로 분리**한다.
- 코일 부하는 끌 때 역전압이 생기므로 1N4148 다이오드로 트랜지스터를 보호한다.

### 4.3 위험도별 출력 (초기값, PRD F3 기준)

| 단계 | PRD 핸들 유닛 | WS2812B 색 (R,G,B) | 부저 | 평균 전류 (MCU 제외) |
|---|---|---|---|---|
| 0 안전 | 꺼짐 | 꺼짐 (0,0,0) | 꺼짐 | 약 1mA |
| 1 주의 | 노랑 LED | (255,180,0) × 밝기 50% | 꺼짐 | 약 15mA |
| 2 경고 | 주황 LED + 짧은 비프 | (255,80,0) × 50% | 2.7kHz 100ms 비프, 1초에 2번 | 약 20mA |
| 3 위험 | 빨강 LED + 연속음 | (255,0,0) × 100% | 2.7kHz 연속 | 약 55mA |
| 연결 끊김 / 저전압 | (PoC 추가) | 파랑 점멸 | 꺼짐 | 약 5mA |

### 4.4 배선도

```
 Li-Po(+) ── 스위치 ──┬── XIAO BAT+
                      ├── 220kΩ ──┬── 220kΩ ── GND
                      │           └── GPIO3 (ADC) ── 100nF ── GND
                      └── WS2812B VDD ── 100µF ── GND
 GPIO10 ── 330Ω ── WS2812B DIN          WS2812B GND ── GND
 XIAO 3V3 ── 부저(+) ── 부저(−) ── S8050 컬렉터      S8050 이미터 ── GND
             └─ 1N4148 (캐소드 → 3V3, 애노드 → 컬렉터)
 GPIO6 ── 1kΩ ── S8050 베이스
 GPIO4 ── 택트 스위치 ── GND (선택, 내부 풀업 사용)
 Li-Po(−) ── XIAO BAT− ── GND (모든 GND 공통)
```

## 5. 전력 예산표

설계는 **평균이 아니라 피크**로 한다. 사용 시간은 배터리 용량의 80%만 쓴다고 보고 계산한다.

### 5.1 후방 유닛 (Li-Po 3.7V 1000mAh)

| 부품 | 전압 | 평균 전류 | 피크 전류 | 평균 전력 (3.7V 기준) |
|---|---|---|---|---|
| XIAO ESP32-C3 (BLE 연결) | 3.3V (내장 LDO) | 60mA | 130mA | 0.22W |
| 1W 빨강 LED (0·1단계 기준) | VBAT 직결 | 90mA | 300mA | 0.33W |
| 분압 회로 | VBAT | 0.01mA | 0.01mA | – |
| **합계** | | **약 150mA** | **약 430mA** | **약 0.56W** |

- 예상 사용 시간: 1000mAh × 0.8 ÷ 150mA ≈ **5.3시간** (3단계가 계속되는 최악 조건 210mA에서도 약 3.8시간)
- 피크 430mA는 배터리 1C(1.0A)의 43%로 여유가 있다.

### 5.2 핸들 유닛 (Li-Po 3.7V 500mAh)

| 부품 | 전압 | 평균 전류 | 피크 전류 | 평균 전력 (3.7V 기준) |
|---|---|---|---|---|
| XIAO ESP32-C3 (BLE 연결) | 3.3V (내장 LDO) | 60mA | 130mA | 0.22W |
| WS2812B (1단계 기준) | VBAT 직결 | 15mA | 40mA | 0.06W |
| 부저 (2단계 기준, 듀티 20%) | 3.3V | 8mA | 40mA | 0.03W |
| **합계** | | **약 85mA** | **약 210mA** | **약 0.31W** |

- 예상 사용 시간: 500mAh × 0.8 ÷ 85mA ≈ **4.7시간**
- 3.3V 레일 부하는 MCU + 부저 피크 약 170mA로, XIAO 내장 LDO 용량 안이다.

## 6. 통신 방식 정리

### 6.1 통신 경로 전체

| 구간 | 방식 | 전압·신호 | 속도·주기 | 비고 |
|---|---|---|---|---|
| 노트북 → 후방·핸들 유닛 | **BLE GATT** (2.4GHz) | 무선 | 연결 간격 7.5~30ms (Windows가 결정) | 노트북 1대가 두 유닛에 동시 연결 (Central 1 : Peripheral 2) |
| ESP32 → 파워 LED | **PWM** (LEDC) | 3.3V 게이트 신호 → MOSFET | 5kHz, 8비트 듀티 | 밝기 = 듀티 |
| ESP32 → WS2812B | **단일선 NZR 직렬 신호** (RMT) | 3.3V 데이터 | 800kbps, 픽셀당 24비트 | 색 바뀔 때만 전송 |
| ESP32 → 부저 | **PWM 구형파** (LEDC) | 3.3V → NPN 베이스 | 2.7kHz, 듀티 50% | 소리 크기는 듀티, 높이는 주파수 |
| 배터리 → ESP32 | **아날로그 ADC** | 0~2.1V (분압 후) | 1초마다 측정 | 12비트 ADC, 여러 번 평균 |
| 노트북 ↔ ESP32 (개발용) | **USB-C** (USB Serial/JTAG) | 5V USB | – | 펌웨어 업로드, 시리얼 로그, 충전 |
| iPhone → 노트북 | 파일 전송 | – | – | 녹화 영상·사진 (실시간 연결 아님) |

### 6.2 BLE GATT 설계

| 항목 | 값 |
|---|---|
| 역할 | 노트북 = Central (`bleak`), 각 ESP32 = Peripheral |
| 장치 이름 | `RG-REAR`, `RG-HANDLE` (bleak가 이름으로 찾아 연결) |
| 서비스 | 사용자 정의 128비트 UUID 1개 (두 유닛 공통) |
| 특성 1: 위험도 | 1바이트 (0~3), **Write Without Response** (응답 대기 없이 보내 지연을 줄임) |
| 특성 2: 배터리 | 1바이트 (%) , Read + Notify (노트북 화면에 표시) |
| 연결 유지 신호 | 위험도가 바뀌지 않아도 노트북이 **200ms마다** 현재 단계를 다시 보냄 |
| 연결 끊김 처리 | 1초 동안 수신이 없으면 후방: 0단계 기본 점등, 핸들: 파랑 점멸 |
| 히스테리시스 | 노트북 쪽에서 처리 (PRD F3 단계 유지 300ms). 유닛은 받은 단계를 그대로 출력 |

### 6.3 지연 시간 예산 (PRD 목표 200ms)

| 단계 | 예상 시간 |
|---|---|
| 프레임 읽기 → 검출·추적·거리·판단 (15 FPS 기준) | 약 67ms 이하 |
| BLE 전송 (연결 간격 1회분) | 약 7.5~30ms |
| ESP32 수신 → GPIO 출력 | 1ms 이하 |
| LED 점등 | 1ms 이하 |
| **합계** | **약 100ms 이하 (목표 200ms 안)** |

## 10. 정리

- **두 유닛 모두 XIAO ESP32-C3 + 1셀 Li-Po**로 통일해, 펌웨어·충전·배선 방식을 하나로 관리한다.
- **GPIO는 신호만, 전력은 트랜지스터가.** 파워 LED(300mA)는 AO3400A, 부저(40mA)는 S8050으로 분리한다.
- **통신은 BLE 1바이트 + 200ms 연결 유지 신호.** 끊기면 후방등은 기본 점등으로 돌아가 안전 쪽으로 실패한다.
- 전류 값은 설계 가정이므로, 조립 후 **H2 전류 실측**과 **H3 지연 실측**으로 이 보고서의 표를 갱신한다.
