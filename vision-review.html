최신 비전 모델 6종 검토

최근 많이 쓰이는 비전 모델 6종이 RearGuard PoC에 도움이 되는지 검토했습니다.

YOLOE DINO-X SAM 3 SigLIP OCR MediaPipe
결론

검출 모델은 YOLO26n 하나로 충분합니다. 6종은 검토만 했고, 실제로는 쓰지 않습니다.

Why YOLO26n Is Enough

왜 YOLO26n으로 충분한가

01

실시간 조건을 더 잘 맞추는 모델이 없음

노트북 CPU에서 15FPS, 프레임에서 LED까지 200ms 이하라는 조건을 YOLO26n보다 잘 만족하는 모델이 6종 중에 없습니다.

02

찾을 대상이 3종으로 고정

RearGuard가 찾는 것은 승용차·대형차·이륜차뿐입니다. 아무 물체나 찾는 능력(오픈 보캐뷸러리)은 필요하지 않습니다.

03

오프라인 도구로도 쓰지 않음

라벨링 초안, 비식별화, 접지점 검증처럼 오프라인 작업에 쓸 여지는 있습니다. 다만 이번 PoC에서는 도입하지 않고 검토 기록으로만 남깁니다.

Model by Model

모델별 판단

YOLOE

검토만

이름만 주면 원하는 물체를 찾는 실시간 YOLO

실시간 경로: 대체할 필요가 없습니다. 같은 크기의 YOLO26n보다 무겁고, 오픈 보캐뷸러리 장점을 쓸 일이 없습니다.

쓴다면: 라벨링 초안, 번호판 위치 찾기

DINO-X

검토만

클라우드 API로 쓰는 고성능 범용 검출 모델

실시간 경로: 쓸 수 없습니다. 클라우드라서 로컬 추론 원칙을 어기고, 네트워크 왕복 때문에 200ms를 맞출 수 없습니다.

쓴다면: 비식별화한 사진의 라벨링 초안

SAM 3

검토만

글자로 지정한 물체를 픽셀 단위로 오려내는 모델

실시간 경로: 쓸 수 없습니다. 파라미터가 848M이라 노트북 CPU에서 실시간으로 돌릴 수 없습니다.

쓴다면: 접지점(박스 아래 변) 정답 검증

SigLIP

검토만

이미지와 문장의 유사도로 분류하는 모델

실시간 경로: 필요 없습니다. 박스를 찾지 못해 검출 모델을 대신할 수 없고, 차종 분류는 YOLO26n이 이미 합니다.

쓴다면: 야간·우천 사진 거르기, 차종 재확인

MediaPipe

검토만

구글의 온디바이스 비전 도구 모음

실시간 경로: 대체할 필요가 없습니다. 검출 정확도(COCO AP 약 25)가 YOLO26n(40.9)보다 크게 낮습니다.

쓴다면: 얼굴 비식별화, 스마트폰 이전 시 참고

OCR

불채택

이미지 속 글자를 읽는 기술

이유: 번호판을 읽는 것은 개인정보를 저장·처리하지 않는다는 원칙과 정반대입니다. 위험 판단에 필요한 정보는 글자가 아니라 위치·궤적·차종입니다.

참고: 번호판 크기로 거리를 확인하는 데에는 위치만 있으면 되므로 OCR이 필요 없습니다.
